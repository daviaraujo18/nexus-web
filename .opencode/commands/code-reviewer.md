description: Revisão completa de código com foco em qualidade e boas práticas
---

Review the code changes and provide a thorough code review covering:

1. **Correctness** — Does the code do what it's supposed to? Any edge cases or bugs?
2. **Code quality** — Readability, maintainability, adherence to project conventions
3. **Performance** — Any obvious performance bottlenecks or unnecessary work
4. **Security** — Injection risks, auth bypasses, data exposure, input validation
5. **Testing** — Are there adequate tests? Are edge cases covered?
6. **Suggestions** — Specific, actionable improvements with code examples

Run `!git diff --stat` and `!git log --oneline -10` for context. Focus on the diff and any related files. Be constructive and specific — reference file paths and line numbers.
